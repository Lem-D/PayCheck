# PayCheck logo PNGs

Ready-to-use PNGs of the PayCheck logo, made from the SVGs in [../mockups/logo](../mockups/logo) (see its README for the design). The marks and wordmarks have transparent backgrounds.

| Files | What it is | Sizes (pixels) |
| --- | --- | --- |
| `paycheck-bill-icon-*.png` | Primary "P Bill" app icon, rounded, on navy | 1024, 512, 256, 180, 128, 64, 32 |
| `paycheck-bill-icon-light-*.png` | The same icon on white | same |
| `paycheck-bill-mark-on-light-*.png` | The bill alone, for light backgrounds | 1024, 512, 256, 128, 64 |
| `paycheck-bill-mark-on-dark-*.png` | The bill alone, for dark backgrounds | same |
| `paycheck-ring-*` | The same four sets for the secondary "Split Ring" logo | same |
| `paycheck-wordmark-on-light-*.png` | The bill and "PayCheck" ("Pay" in navy, "Check" in gold) for light backgrounds | 512, 256, 128 tall |
| `paycheck-wordmark-on-dark-*.png` | The wordmark for dark backgrounds | same |

180 is the iPhone home screen size and 32 is a browser tab icon. The app's own icon files are in `mobile/assets/` and `mobile/public/`.
