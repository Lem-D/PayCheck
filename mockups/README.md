# Mockups

The design work from Oct 14 that led to the app's current look and logo. These are reference only; the app itself is in `../mobile`.

| File | What it is |
| --- | --- |
| [paycheck-looks.html](paycheck-looks.html) | The first round: the original look next to four alternatives (A Harbour rings and tiles, B Envelopes, C Receipt, D Sunrise), each on the Payday, Spending, Goals and Accounts screens. Hosted: [PayCheck Looks](https://claude.ai/artifact/MMBRiHhCp5Hqx2Rfi82chs). |
| [harbour-palettes.html](harbour-palettes.html) | The second round: the Harbour rings-and-tiles layout in fifteen palettes, each in light and dark. Harbour Gold is the first row. Hosted: [Harbour Palettes](https://claude.ai/artifact/HGaD5gxYmyYcCJRJtkhLCr). |
| [logo/](logo) | The logo work: [concepts.html](logo/concepts.html) with all fourteen concepts (A to N), and the final files for K "P Bill" (main logo, used for the app icon and splash) and A "Split Ring" (second logo). See [logo/README.md](logo/README.md). Hosted concepts: [PayCheck Logo Concepts](https://claude.ai/artifact/WDJoEpY67dNyUdK5ZeFgjd). |
| [harbour-gold-spec.md](harbour-gold-spec.md) | The chosen design: Harbour Gold colour tokens for light and dark, and the layout of each screen. |
| [screenshots/](screenshots) | The phone app after the redesign, all four tabs in light and dark, with example numbers. |

Open the HTML files in a browser. They load the Outfit and Figtree fonts from Google Fonts, so they look right when you're online.

The decision: rings and tiles (option A) with the Harbour Gold palette, following the phone's light or dark setting. The DESIGN.md "Look" section describes how it's built in the app.
